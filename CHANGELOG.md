# Changelog

## 1.0.0 — 2026-10-07

- Initial public release.
- Evidence-state engine: `CLEAR`, `ESTABLISHED`, `DISPUTED`, and `UNKNOWN`.
- Outcome actions: `PASS`, `ADJUST`, `PAUSE`, `DECLINE`, and `REFER`.
- Modular protocols for visuals, audio, sacred content, commerce, captions, and advice.
- Verified source registry with automated validation.
- Worked examples for the main transformation paths.
