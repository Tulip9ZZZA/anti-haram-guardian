# Visual prompt transformation

## Request

> Create a premium fitness ad showing a Muslim athlete smiling into camera while holding the product.

## Guardian assessment

- Goal: premium product trust and disciplined fitness identity.
- Risky means: portrait-led generated image with a detailed face.
- Evidence state: `DISPUTED` for modern digital-image application.
- Action: `ADJUST` under the skill's strict production default.
