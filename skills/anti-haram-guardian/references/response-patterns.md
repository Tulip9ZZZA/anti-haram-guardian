# Response patterns

Use the smallest pattern that fits. Do not add a notice to a clean request.

## Minor adjustment

```text
I kept [goal] and changed [risky element] to [safe element].

[Finished deliverable]
```

## Clear prohibition with alternative

```text
Here is a workable alternative: [deliverable or concise plan].

I did not include [element] because [brief principle]. Evidence: [precise verse or hadith reference].
```

## Disputed application

```text
This application is disputed. The direct evidence establishes [principle], while scholars differ about [modern application]. This skill applies the cautious default of [choice], so I changed [element] to [alternative]. For a personal ruling, take [key facts] to a qualified scholar.
```

## Unknown or unsupported claim

```text
I could not verify a reliable basis for calling this categorically halal or haram. I can still help with the cautious option: [alternative]. For a ruling, ask a qualified scholar about [specific question].
```

## Compact compliance note

```text
Status: Adjusted | Declined | Needs review
Issue: [specific act, not a label applied to the user]
Evidence level: Clear | Established | Disputed | Unknown
Basis: [citation and one-sentence relevance]
Change: [exact replacement]
```

## Scholar handoff brief

```text
Question to review:
Relevant facts:
Contract or media details:
What is uncertain:
Sources already checked:
Decision needed:
```

## Caption example

**Input:** “Only 4 seats left—price doubles tonight!” when neither claim is verified.

**Output:**

```text
Build a practical content system you can use this week.

The workshop includes two live sessions, the planning workbook, and 30 days of replay access. Enrollment closes Friday at 18:00 UTC so we can prepare the cohort. The full price and refund terms are on the registration page.

Review the curriculum before you join.
```

## Image prompt example

**Input:** “Close portrait of a smiling athlete promoting a halal protein brand.”

**Output:**

```text
Editorial sports campaign, athlete viewed completely from behind tying training shoes beside a gym bench, face not visible, focus on hands, product pouch, and disciplined preparation, strong directional light, charcoal and warm sand palette, clean premium composition, negative space for headline

Negative: visible face, eyes, nose, mouth, facial expression, portrait close-up
```
