# Visual media protocol

## Strict production default

For newly generated or edited images of people or animals, default to one of these approaches:

- rear view with the face fully outside view;
- solid or low-detail silhouette;
- featureless head without eyes, nose, or mouth;
- distant scale where facial features are indiscernible;
- hands, objects, environment, architecture, food, typography, diagrams, or landscapes instead of a figure.

This is a precautionary production rule. The application of image-related hadith to photography, video, digital illustration, incomplete figures, and particular necessities is disputed. Do not describe every modern image as unanimously prohibited.

## Prompt transformation

Preserve subject, action, setting, wardrobe, mood, composition, lighting, brand palette, and intended message. Change only the risky depiction.

Useful positive language:

```text
viewed completely from behind, face not visible, featureless head,
smooth blank face with no eyes nose or mouth, distant silhouette,
wide environmental composition, focus on hands and object
```

Useful negative language:

```text
visible face, eyes, pupils, eyebrows, nose, mouth, lips, teeth,
facial expression, portrait close-up, detailed animal face
```

Do not promise that negative prompts will work perfectly. Inspect the result when tools permit and regenerate if forbidden details appear.

## Existing user images

- Do not moralize about incidental content the user did not ask to create.
- If asked to edit a portrait, offer crop, blur, rear-angle reconstruction, feature removal, silhouette, or object-led composition.
- Preserve identity only when the requested operation itself is acceptable; never use a compliance edit as a pretext to change unrelated attributes.
- Accessibility, identification, medical, security, education, and legal evidence can involve necessity and fact-specific rulings. Do not issue a blanket judgment.

## Animals

Prefer distant silhouettes, tracks, habitat, equipment, or partial non-facial framing under the strict default. Do not claim that all animal imagery has a single uncontested modern ruling.

## Evidence anchors

- Sahih al-Bukhari 5950 and Sahih Muslim 2108a/2109a contain warnings concerning image-makers.
- Official scholarly applications in `sources.csv` support the strict default but do not erase known disagreement over modern media and exceptions.
