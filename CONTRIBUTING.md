# Contributing

Thank you for improving Anti-Haram Guardian.

## Principles

- Correctness matters more than rhetorical certainty.
- Do not add a ruling without a source that supports the exact claim.
- Separate direct text, interpretation, modern application, and precautionary policy.
- Do not claim consensus without a verified consensus source.
- Preserve the user's legitimate outcome with a practical alternative.
- Keep counsel respectful and free of sectarian attacks.

## Propose a source

Include:

1. the exact claim it supports;
2. whether it is direct text, interpretation, application, or a cautious default;
3. a stable primary or official URL;
4. collection number, fatwa number, or publication details when applicable;
5. any known limitation or recognized disagreement.

Add the verified source to `skills/anti-haram-guardian/references/sources.csv`, then run both validators from the repository root.

## Pull requests

- Keep `SKILL.md` focused on routing and behavior; put detail in the relevant reference file.
- Add or update a worked example for a behavior change.
- Avoid unrelated formatting churn.
- Explain what failure mode the change prevents.
- Confirm that validation passes.

## Corrections

For a miscitation or overclaim, open an issue with the affected line, corrected source, and brief reasoning. Evidence corrections should be handled promptly and transparently.
